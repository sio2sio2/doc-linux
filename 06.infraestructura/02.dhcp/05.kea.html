6.1.5. Kea DHCP¶

El servidor Kea es el remplazo del ISC para su antiguo servidor, cuyo desarrollo abandonó definitivamente en 2022. Tiene un diseño modular más moderno y permite el almacenamiento de asignaciones en bases de datos.

Ilustremos su configuración para el mismo servidor que ya hemos ido estudiando: uno que tiene una interfaz externa a través de la cual no queremos proporcionar configuraciones de red y dos interfaces internas a través de las que sí:

# Interfaz externa.
allow-hotplug eth0
iface eth0 inet dhcp

# Red interna 1 (interna1.local)
allow-hotplug eth1
iface eth1 inet static
   address 192.168.255.1/24

# Red interna 2 (interna2.local)
allow-hotplug eth2
iface eth2 inet static
   address 192.168.254.1/24

Debian separa los módulos del servidor en distintos paquetes. Como, en principio, sólo nos interesa aprender cómo se configura de forma básica para IPv4:

# apt install kea-dhcp4-server

6.1.5.1. Configuración básica¶

La configuración del servidor se encuentra toda dentro del directorio /etc/kea y es ahí donde debemos crear los archivos de configuración. Debe crearse un archivo independiente por cada módulo del servidor (p.ej. un archivo para el módulo encargado de IPv4 y otro distinto para el módulo encargado de IPv6) y, en teoría, los nombres son arbitrarios. Sin embargo, la configuración del servicio en Debian está pensada para que en el caso del módulo para IPv4 el nombre del archivo sea kea-dhcp4.conf (que por otro lado el nombre que suele asignarse por convención).

Así pues comencemos por una configuración muy, muy básica con la que se proporciona configuraciones a una red sin distinguir máquinas clientes:

{
   "Dhcp4": {
      "interfaces-config": {
          // Intefaces por las que se proporciona configuración de red
         "interfaces": [ "eth1" ]
      },

      // Almacenamiento de las asignaciones (sin base de datos: CSV)
      "lease-database": {
         "type": "memfile",
         "persist": true,
         "name": "/var/lib/kea/kea-leases4.csv"
      },

      // -- Parámetro globales
      "authoritative": true,
      "valid-lifetime": 6000,
      "max-valid-lifetime": 7200,

      // -- Opciones DHCP aplicables a todas la redes
      "option-data": [
         {
            "name": "ntp-servers",
            "data": "hora.roa.es"
         }
      ],

      // -- Configuración de subredes
      "subnet4": [
         {
            "subnet": "192.168.255.0/24",
            // Opciones DHCP específicas de esta subred
            "option-data": [
               {
                  "name": "routers",
                  "data": "192.168.255.1"
               },
               {
                  "name": "domain-name-servers",
                  "data": "192.168.255.1"
               },
               {
                  "name": "domain-name",
                  "data": "smr2.luna"
               },
               {
                  "name": "broadcast-address",
                  "data": "192.168.255.255"
               }
            ]
            // Pools de asignaciones.
            "pools": [
               {
                  "pool": "192.168.255.100 - 192.168.255.150"
               }
            ],
         }
      ]
   }
}
